# British-Airways-Customer-Review-Dashboard-Tableau
An interactive Tableau dashboard that analyses British Airways customer reviews from March 2016 to October 2023, looking at how passengers rate the airline overall and across six service areas, and how those ratings vary by country, aircraft, traveller type, seat class and time.

## Project Overview

Airlines collect large volumes of customer feedback, but it is hard to act on in raw form. This project turns a review dataset into a single dashboard that lets a user quickly see where British Airways is performing well, where it is falling short, and how perception has changed over time.

## Dashboard Components

**KPI Summary**: Average overall rating plus average scores for Cabin Staff Service, Entertainment, Ground Service, Food & Beverages, Seat Comfort and Value for Money 
**Average Rating by Month**: Line chart of rating trends from 2016 to 2023 
**Average Rating by Country**: Choropleth map showing average rating by reviewer country 
**Average Rating by Aircraft**: Side-by-side bar charts comparing average rating and number of reviews for each aircraft type 

### Interactive Controls
**Metric selector**: Switch every chart between Overall Rating, Cabin Staff Service, Entertainment, Food & Beverages, Ground Service, Seat Comfort and Value for Money
**Filters**: Month of Date, Continent, Traveller Type, Seat Type and Aircraft
